Reliquary

Your worlds, your servers, your relic. A gaming-first, self-hostable communication client — own your space, no platform in the middle.

Download for Windows Windows 10/11 · free & open source · pre-alpha

◆ One-click installer

Fetches the latest client straight from the source and sets it up. Updates land automatically from inside the app.

🛡 Verified download

The installer checks each download against the publisher's SHA-512 checksum before it runs — a tampered file is refused.

⌂ Self-hosted

Run your own server (a "Keep") on your own hardware. Your worlds, your rules, your data.

A note on privacy: Reliquary is decentralized — when you join a Keep you connect directly to whoever hosts it, so that host can see the network address you connect from, like any server you join. Other members cannot. If you'd like to mask your address, use a VPN and only join Keeps you trust. See the privacy notes.
